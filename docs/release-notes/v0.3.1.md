Ágora 0.3.1 arregla la cámara en el Mac, que seguía sin arrancar.

*Ágora 0.3.1 fixes the camera on the Mac, which still would not start.*

## Español

### Correcciones

- **La cámara arranca en el Mac.** La 0.3.0 probaba varios modos, pero el primer paso (abrir la cámara) ya fallaba con «640x480@15FPS YUYV Not Found/Rejected/Unsupported»: macOS anuncia los dos extremos de cada rango de fotogramas, pero solo deja fijar el más alto, y Ágora abría la cámara con el más bajo. Ahora se abre con el modo de mayor frecuencia (siempre aceptado), pasa después a un modo más pequeño si la cámara lo acepta, y si la apertura falla cuenta el motivo de cada intento en lugar de un solo error.

## English

### Fixes

- **The camera starts on the Mac.** 0.3.0 tried several modes, but the first step (opening the camera) already failed with "640x480@15FPS YUYV Not Found/Rejected/Unsupported": macOS lists both ends of each frame-rate range but only lets the top one be set, and Ágora opened the camera at the low end. It now opens with the highest-rate mode (always accepted), moves to a smaller mode afterwards if the camera accepts one, and if opening fails it reports the reason for each attempt instead of a single error.
