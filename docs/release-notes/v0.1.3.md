Ágora 0.1.3 refuerza el registro y añade una forma de revocar otras sesiones.

*Ágora 0.1.3 strengthens registration and adds a way to revoke other sessions.*

## Español

### Correcciones

- El uso de una invitación y la creación de la cuenta se realizan en una sola transacción, para evitar registros con invitaciones agotadas o caducadas.
- Los servidores nuevos requieren un token de instalación de un solo uso para crear la primera cuenta. Los servidores con cuentas existentes se reconocen como inicializados durante la migración.
- La API permite revocar las demás sesiones tras verificar la contraseña; la sesión actual se conserva. Esta operación no incorpora todavía una pantalla de gestión de dispositivos.

### Antes de actualizar el servidor

- Haz una copia consistente de SQLite y comprueba su restauración en una instalación de prueba antes de actualizar. Las migraciones se ejecutan al iniciar y no tienen vuelta automática; consulta `docs/deployment.md`.
- La autenticación de dos factores obligatoria y su migración aún no están implementadas. Esta versión no cambia esa situación.

## English

### Fixes

- Invitation redemption and account creation are performed in one transaction to prevent registration with expired or exhausted invitations.
- New servers require a one-use installation token for the first account. Servers with existing accounts are marked initialized during migration.
- The API can revoke other sessions after password verification, preserving the current one. A device-management screen is not yet included.

### Before updating the server

- Take a consistent SQLite backup and verify restoration on a test installation before updating. Migrations run on startup and do not automatically roll back; see `docs/deployment.md`.
- Mandatory two-factor authentication and account migration are not yet implemented.
