Ágora 0.1.2 trae el servidor como paquete propio, fácil de instalar en cualquier máquina Linux, los botones de la ventana integrados en macOS y la app en el idioma del sistema.

*Ágora 0.1.2 ships the server as its own package, easy to install on any Linux machine, integrates the window buttons on macOS, and follows the system language.*

## Español

### Novedades

- **El servidor, por separado.** Cada versión trae el servidor solo, sin la app ni sus librerías gráficas: un `.tar.gz` con `install.sh`, y paquetes `agora-server` `.deb` y `.rpm`. Instalan el servicio de systemd `agora-server`, su usuario `agora`, los datos en `/var/lib/agora` y la configuración en `/etc/agora/agora.toml`, que se respeta al actualizar. Sirve para un servidor Debian o Ubuntu, un contenedor LXC de Proxmox o un VPS pequeño.
- **Guía para Proxmox** en `docs/deployment.md` y en el `README.md` del paquete del servidor.
- **macOS:** los botones de la ventana están dentro de la ventana, sobre la barra superior de Ágora, en lugar de en una barra aparte. La barra superior también sirve para mover la ventana.

### Correcciones

- La app sale en español cuando el sistema está en español. En macOS y Windows se leía solo la variable `LANG`, que una app abierta desde el Dock o el menú Inicio no tiene, y la app salía en inglés.

### Cambios

- Los paquetes `.deb`, `.rpm` y `.tar.gz` de la app ya no traen el servidor: está en `agora-server`.

## English

### What's new

- **The server on its own.** Every release carries the server alone, without the app or its graphics libraries: a `.tar.gz` with `install.sh`, and `agora-server` `.deb` and `.rpm` packages. They install the `agora-server` systemd service, its `agora` user, the data in `/var/lib/agora` and the configuration in `/etc/agora/agora.toml`, which upgrades keep. It suits a Debian or Ubuntu server, a Proxmox LXC container or a small VPS.
- **A Proxmox guide** in `docs/deployment.md` and in the server package's `README.md`.
- **macOS:** the window buttons sit inside the window, over Ágora's top bar, instead of in a separate strip. The top bar also moves the window.

### Fixes

- The app shows in Spanish when the system is in Spanish. On macOS and Windows it read only the `LANG` variable, which an app opened from the Dock or the Start menu doesn't have, so it came up in English.

### Changes

- The app's `.deb`, `.rpm` and `.tar.gz` no longer carry the server: it is in `agora-server`.
