Ágora 0.1.5 busca actualizaciones desde la app y, en el servidor, se actualiza solo.

*Ágora 0.1.5 checks for updates from the app and, on the server, updates itself.*

## Español

### Novedades

- La app de escritorio busca actualizaciones al abrirse y desde el menú (Buscar actualizaciones…). Muestra las notas de la versión nueva y, en el AppImage, macOS y Windows, la descarga, la comprueba y se reinicia ya actualizada. Si se instaló con un paquete del sistema, abre la página de la versión.
- El servidor se actualiza solo a la última versión estable: lo comprueba una vez al día, descarga el paquete, hace una copia de la base de datos y se reinicia. `agora-server self-update` lo hace en el momento, y se puede desactivar en la configuración.

### Correcciones

- Buscar actualizaciones no falla con «http status: 403» cuando GitHub limita las consultas, y una descarga que se para sigue desde donde se quedó en lugar de cortarse a mitad.

## English

### New

- The desktop app checks for updates when it opens and from the menu (Check for Updates…). It shows the new version's notes and, on the AppImage, macOS and Windows, downloads it, verifies it and restarts updated. Installed from a system package, it opens the release page.
- The server updates itself to the latest stable release: it checks once a day, downloads the package, backs up the database and restarts. `agora-server self-update` does it at once, and it can be turned off in the configuration.

### Fixes

- Checking for updates no longer fails with "http status: 403" when GitHub limits requests, and a download that stalls carries on from where it stopped instead of failing part way.
