Ágora 0.1.4 ajusta la alineación de los mensajes y de los títulos de canal.

*Ágora 0.1.4 adjusts message and channel heading alignment.*

## Español

### Correcciones

- Los mensajes consecutivos del mismo autor mantienen el espacio reservado para el avatar y se alinean con el primer mensaje.
- Ajusta la posición del título de canal junto a su icono, con y sin tema.

### Servidor

- El comando `agora-server check-updates` consulta si hay una versión estable nueva; `agora-server backup` crea una copia consistente de SQLite sin sobrescribir una existente.
- Esta versión no incorpora todavía un actualizador automático del servidor ni autenticación de dos factores obligatoria.

## English

### Fixes

- Consecutive messages from the same author keep the avatar column and align with the first message.
- Adjusts the channel heading position next to its icon, with and without a topic.

### Server

- `agora-server check-updates` checks for a newer stable version; `agora-server backup` creates a consistent SQLite snapshot without overwriting an existing file.
- This release does not yet include automatic server updates or mandatory two-factor authentication.
