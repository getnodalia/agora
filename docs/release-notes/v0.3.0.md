Ágora 0.3.0 trae recuperación de contraseñas sin correo, eliminar espacios de trabajo, un asistente para conectar Hito y otras apps, y una interfaz más cuidada.

*Ágora 0.3.0 brings password recovery without email, deleting workspaces, a guided way to connect Hito and other apps, and a more polished interface.*

## Español

### Novedades

- **Recuperar la contraseña sin correo.** Cada cuenta puede tener una clave de recuperación (las cuentas nuevas la reciben al registrarse, y se crea en Seguridad y dispositivos). Si olvidas la contraseña, «¿Has olvidado tu contraseña?» en la pantalla de inicio de sesión te deja elegir una nueva con esa clave. Si no la guardaste, quien administra el servidor puede darte un código de un solo uso con `agora-server reset-password USUARIO`. Las cuentas con verificación en dos pasos siguen pidiendo su código. Restablecer cierra las demás sesiones y no pierde conversaciones.
- **Cambiar la contraseña** desde Seguridad y dispositivos.
- **Eliminar un espacio de trabajo**: solo su propietario, escribiendo su nombre para confirmar. Se borra todo lo que contiene y quienes lo usan lo ven desaparecer al momento.
- **Pestaña de plugins para las conexiones**: la ventana de Integraciones tiene una galería de plugins con iconos (Hito, GitHub, servidor de compilación, monitorización, script y cualquier otra app) junto a la lista de lo conectado. Hito se conecta con un clic y el resto tiene su asistente con la dirección y la clave listas para copiar, un comando de ejemplo y un botón para enviar un aviso de prueba. Cada conexión muestra su último aviso.
- **Conexión con GitHub, guiada y robusta**: el plugin de GitHub te da la dirección y la clave con los pasos exactos para añadir el webhook en el repositorio. Ágora entiende las cabeceras de GitHub tal cual, acepta sus dos formatos de contenido y convierte pushes, pull requests, incidencias, comentarios, reseñas, versiones y ejecuciones fallidas en un aviso legible en el canal. El resto de eventos se aceptan sin ruido. Cada repositorio tiene su propia clave.
- **Diálogos que explican lo que hacen**: crear un canal (con vista previa del nombre y qué significa privado), invitar (usos y caducidad claros), eliminar un mensaje, y el menú de espacios de trabajo con tu rol en cada uno. Los botones de los detalles del canal ahora son uniformes.
- **La cámara arranca en el Mac**: macOS anunciaba un modo de 15 fotogramas que luego rechazaba y la cámara no mostraba nada. Ágora ahora prueba los modos por orden hasta que la cámara acepta uno, y si no acepta ninguno usa el suyo.
- **Errores en tu idioma y con una pista**: «No se puede conectar con el servidor» en vez de textos técnicos en inglés.

### Notas

- Para actualizar un servidor, basta ejecutar `agora-server self-update` (o esperar a la actualización diaria). El protocolo solo ha crecido, así que las versiones 0.2.x siguen conectándose, aunque sin las funciones nuevas.
- Restablecer con una clave de recuperación no restaura mensajes que este equipo no pudiera leer antes: las claves de cifrado de cada equipo no dependen de la contraseña.

## English

### What's new

- **Password recovery without email.** Every account can have a recovery key (new accounts get one at sign-up, and it can be made in Security and devices). If you forget your password, "Forgot your password?" on the sign-in screen lets you choose a new one with that key. If you did not save it, whoever runs the server can give you a one-use code with `agora-server reset-password USERNAME`. Accounts with two-step verification still need their code. A reset signs out the other sessions and loses no conversations.
- **Change your password** from Security and devices.
- **Delete a workspace**: only its owner, by typing its name to confirm. Everything in it is erased and the people using it see it disappear at once.
- **A Plugins tab for connections**: the Integrations window has a gallery of plugins with icons (Hito, GitHub, build server, monitoring, script, any other app) next to the list of what is connected. Hito connects in one click, and the others get a wizard with the address and key ready to copy, an example command and a button that sends a test notice. Each connection shows its latest notice.
- **A guided, robust GitHub connection**: the GitHub plugin gives you the address and key with the exact steps to add the webhook on the repository. Ágora understands GitHub's own headers, accepts both of its content types and turns pushes, pull requests, issues, comments, reviews, releases and failed workflow runs into a readable notice in the channel. Every other event is accepted without noise. Each repository has its own key.
- **Dialogs that explain what they do**: creating a channel (with a name preview and what private means), inviting (clear uses and expiry), deleting a message, and the workspace menu showing your role in each. The buttons in a channel's details are now uniform.
- **The camera starts on the Mac**: macOS listed a 15 frames-per-second mode and then refused it, so the camera showed nothing. Ágora now tries the modes in order until the camera accepts one, and uses its own if it accepts none.
- **Errors in your language, with a hint**: "Cannot reach the server" instead of technical English text.

### Notes

- To update a server, run `agora-server self-update` (or wait for the daily update). The protocol only grew, so 0.2.x apps still connect, without the new features.
- Resetting with a recovery key does not bring back messages this computer could not read before: each computer's encryption keys do not depend on the password.
