# Security policy

Please report a vulnerability in Ágora privately through
[GitHub private vulnerability reporting](https://github.com/getnodalia/agora/security/advisories/new),
not in a public issue or pull request. Say which version you ran, on which platform, and how to
reproduce the problem.

Nodalia maintains Ágora and handles every report. Only the latest release receives security fixes.

Nothing has been released yet; until the first release, fixes land on `main`. The security model,
what Ágora protects and what it does not, is in [docs/security.md](docs/security.md).
